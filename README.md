# LiD für Milos

Übung für den Test **Leben in Deutschland** (Baden-Württemberg).

- 300 allgemeine Fragen + 10 Landesfragen
- Lernen mit sofortiger Lösung
- Prüfung: 33 Fragen, 60 Minuten, 17 Richtige zum Bestehen
- Fortschritt nur im Browser (localStorage)

Quelle: BAMF-Gesamtfragenkatalog, Stand 07.05.2025. Keine amtliche Prüfung.

```bash
npm install
npm test
npm run build
```
